Overview

The timeline follows a vendor's lifecycle, stage by stage, in the order kept in tools/event-model/story.mjs; a slice missing from it shows under Unsorted. Each framed column is a slice. The top lanes say who acts: a screen per actor, Stripe, or an automation's gear. The spine holds commands and read models; below it, one lane per event stream, grouped by bounded context. An automation's gear sits over each command it sends, its trigger running from the event straight to the gear.

Specifications hang under their column: Given, When, Then, read off each spec's own body. An automation's spec goes under the gear over the command whose event it asserts, else the command it asserts it sends, else under every one of its gears; a command placed twice files each spec wherever everything it is given has happened by then.

Every card comes from source: slices and specifications in test/src/<context>, lanes and wiring in packages/<context>, actors in the api's controllers, the operator console under ops/, and Stripe's webhooks. Regenerate with npm run event:model.
